# [web] web-subnetalpha

**Topic:** subnetalpha.ai as a scraping target + alternative Bittensor subnet directories (identity/link coverage, APIs, rate limits, ToS)

## Findings

## 1. subnetalpha.ai — platform and enumeration

**Stack (verified from raw HTML/headers, 2026-09-22):** WordPress 7.1.1 + Elementor Pro 4.2.4 (Hello Elementor theme), Yoast SEO 28.5, ACF, Custom Post Type UI, **Custom Twitter Feeds Pro** (`ctf/v1`), LiteSpeed cache, Cloudflare (email obfuscation only; plain `curl` with a browser UA gets HTTP 200, no JS challenge). GA4 `G-D479N7QNZJ`. Maintainer: "The Realistic Trader". Site self-describes as "an informational platform for Bittensor Subnets"; footer note: "data may be slightly out of date from time to time". **No ToS/privacy/legal page exists** (page-sitemap lists only 10 pages: /, /home/, /subnet-template/, /subnet-access/, /test/, /twitter-test/, /validators/, /dtao/, /what-is-bittensor/, /extra-resources/). Copyright 2024.

**robots.txt:** `User-agent: * / Disallow:` (empty = allow all). `Sitemap: https://subnetalpha.ai/sitemap_index.xml` → `page-sitemap.xml` + `subnet-sitemap.xml` (**128 `<loc>` entries with `<lastmod>`**, e.g. `https://subnetalpha.ai/subnet/computehorde/` 2025-09-26; `.../subnet/cartha/` 2026-08-27T11:48:17Z).

**URL slug pattern:** `https://subnetalpha.ai/subnet/{slug}/`. Slug is editorial, NOT the netuid: `apex`, `dsperse`, `data-universe`, `base-sn100`, `sundae_bar`, `its-ai`, and placeholder slugs `subnet03`, `subnet7`, `subnet15`, `subnet39`, `subnet42`, `subnet57`, `subnet70`, `subnet73`, `subnet81`, `subnet84`, `subnet-85`, `subnet86`, `subnet94`, `subnet103`. Netuid must be derived from the ACF field `subnet_number` (string "Subnet 01" … "Subnet 128"; regex `(\d+)`). Slugs can change on rebrand (e.g. `subnet-85` now VIDAIO) — key records by netuid, keep slug as a secondary attribute.

**Best enumeration path = WordPress REST (no auth, no key):**
- `GET https://subnetalpha.ai/wp-json/wp/v2/subnet?per_page=100&page=1` and `&page=2` → 128 records. Headers: `X-WP-Total: 128`, `X-WP-TotalPages: 2`, `Link: <...page=2>; rel="next"`. Supports `_fields=slug,title,acf,modified,link` (the old bot already does this: `E:\SN_Trader\SubnetTrader\app\data\fundamentals_collect.py:73-111`). WP returns 400 past the last page.
- Record shape: `id, date, modified, modified_gmt, slug, status, type="subnet", link, title.rendered, content.rendered` (always empty — all content is in `acf`), `author` (one WP user per subnet, ids 2..119), `meta{_acf_changed,footnotes}`, `acf{...}`, `yoast_head_json.article_modified_time`.
- Also: `GET /wp-json/wp/v2/types` confirms CPT `subnet` (`rest_base: "subnet"`). Site-level namespaces: `subnetalpha/v1`, `ctf/v1`, `cptui/v1`, `yoast/v1`, `elementor/v1`, etc.

**ACF fields (32, all present on every record; non-empty counts /128):**
`subnet_number` 128 · `short_desc` 128 · `what_exactly_does_it_do` (ABOUT) 128 · `what_exactly_is_the_productbuild` (PURPOSE) 128 · `subnet_owner` 128 (15 = "Unknown") · `team_info` (WHO, HTML) 128 · `roadmap` (FUTURE, HTML) 128 · `infographic` (WP media id) 113 · `twitterx_url` 102 (100 x.com, 2 twitter.com) · `github_url` 106 (all github.com) · `discord_url` 112 (88 `discord.com/invite/...`, 24 `discord.gg/...`; none are channel deep-links) · `website_url` 104 · `telegram_url` 7 (t.me) · `twitter_embed_id` 74 · `video_url`/`video_description` 58 · `additional_video_1..8` 43/24/16/11/7/4/1/0 with matching `video_description_N`.

**Team / doxxing quality:** `team_info` median 1,572 chars (min 13, max 6,680). Only **16/128 records contain LinkedIn URLs** (162 distinct `linkedin.com/in|company/` URLs total, concentrated in the big teams e.g. Apex/Macrocosmos with `<a href="https://www.linkedin.com/in/willsquires/...">`). **70/128 records mark names with `<strong>`** (354 names) usually as `<strong>Name</strong> – Role`; 7 records embed X profile links for team members. ~15 records are placeholders (`Awaiting Data...`, `Awating Data...` [sic], `No team members have been publicly disclosed`, `The core team behind ORO is kept private`). Recent write-ups (Aug 2026 refresh) are LLM-style prose with headings like `<strong>Public Team Members and Handles:</strong>` and `<strong>GitHub Contributors and Activity:</strong>` — useful text but not structured; some contain leaked ChatGPT markup (`data-start=`, `class="text-token-text-primary"`).

**Roadmap quality:** median 1,906 chars; 75/128 mention `Q1-4` or a year 2024-2029; 17 are <200 chars; 1 literal placeholder ("Subnet Roadmap" on `apex`). Again HTML prose, frequently `<ul><li><strong>Phase N – ...</strong>`.

**Last-updated:** per record `modified`/`modified_gmt` (also `article:modified_time` meta on the page and sitemap `lastmod`). Distribution: 2025-09: 4, 2025-10: 24, 2025-12: 5, 2026-01: 2, 2026-02: 1, 2026-03: 2, 2026-05: 7, 2026-06: 1, **2026-08: 82** (bulk refresh 2026-08-13…27). Created dates: 2024-04 (32), 2024-08…2025-06. No per-field timestamps; a `modified` bump does not say which field changed → diff ACF JSON snapshots yourself.

**Rendering:** Editorial sections (ABOUT / PURPOSE / WHO / FUTURE / MEDIA / NEWS "Announcements") are **server-rendered** in the HTML (team names + LinkedIn hrefs present in raw HTML, 44 linkedin occurrences on /subnet/apex/). The **financial metrics box is JS-filled**: inline `var TAOSCAN = '/?rest_route=/subnetalpha/v1/subnet-stats'` then `fetch(TAOSCAN)`; labels: Alpha Price, Market Cap, Neurons, Registration Cost, TAO Liquidity, Alpha in Pool, Total Alpha Supply, % Alpha Staked (empty in static HTML). The NEWS Twitter feed is server-rendered by Custom Twitter Feeds Pro: ~12 tweets in `.ctf-item` with `.ctf-tweet-text`, `.ctf-tweet-date` (format "16 Sep" — no year), `data-feedid="1"`; only present where `twitter_embed_id` is set (74 pages). The `ctf/v1` REST namespace exposes no public routes.

**Custom endpoint `GET /wp-json/subnetalpha/v1/subnet-stats`** (Cache-Control `public, max-age=60`, LiteSpeed cached; ~201 KB): `{subnets[129], subnetsInfo[129], blockNumber, fetchedAt(ms epoch), snapshots{now,day,week: block}, hyperparams[], delegates[], neurons[]}` — last three empty. `subnets[]` keys: `netuid, subnet_name, name, description, github_repo, subnet_contact, subnet_url, logo_url, discord, additional, subnet_contact_twitter (always null), tags (null), symbol, alpha_in_pool, alpha_staked, total_alpha, total_tao, liquidity, tao_volume_24_hr, market_cap, price, price_change_1_day/1_hour/1_week, seven_day_prices, timestamp, block_number, rank, tao_buy/sell_volume_24_hr, buys/sells/buyers/sellers_24_hr, alpha_in_emission, alpha_out_emission, pending_root_prop, subnet_volume, tao_volume_7d`. Coverage: github_repo 107/129, subnet_url 102, discord 61, subnet_contact 75, logo_url 98, additional 30, description 108. **All volume/price-change/buy-sell/seven_day_prices fields are 0/empty → not a market-data source.** `subnetsInfo[]` adds `summary, tags, twitter` — all null. **Data bug:** identity strings carry a leaked SCALE compact-length prefix in 28/108 descriptions and many `subnet_contact`/`subnet_url`/`additional` values (e.g. `"PCoordinated Learning"`, `",ByteLeap.ai"`, `"Larbos@bittensor.com"`, 2-byte prefix `"5\x02Chutes is a subnet..."` when len ≥ 64). Normalise with: if `(ord(s[0])>>2)==len(s)-1` strip 1 char; if `(ord(s[0])&3)==1` and `((ord(s[0])|ord(s[1])<<8)>>2)==len(s)-2` strip 2. Prefer on-chain/TaoStats/taomarketcap for identity strings; use subnetalpha only for the editorial ACF.

**Scrape plan:** 2 REST calls (CPT) + 1 (`subnet-stats`) per run; poll `modified_gmt` daily; fetch a profile HTML page only when you want the tweet feed (74 pages; HTML ~230 KB each). Set a descriptive UA; 1 req/s is polite (no published limit). No ToS restricts it; robots allows all.

## 2. Alternative directories (identity/link coverage)

**A. On-chain `SubtensorModule.SubnetIdentitiesV3`** (map netuid → struct, `opentensor/subtensor/pallets/subtensor/src/lib.rs:451`): `subnet_name ≤256B, github_repo ≤1024, subnet_contact ≤1024, subnet_url ≤1024, discord ≤256, description ≤1024, logo_url ≤1024, additional ≤1024` (`utils/identity.rs:205-230`). **No twitter/X field on-chain.** SDK: `AsyncSubtensor.all_subnets()` → `DynamicInfo.subnet_identity` (old bot `fundamentals_collect.py:117-157`; archive node `wss://archive.chain.opentensor.ai:443`). tao.app defines a "TAOAppv1" JSON payload owners can put in `additional` (tagline, category, tags, links, About) — decode via their `/api/beta/subnets/owner-content`.

**B. TaoStats API** (`https://api.taostats.io`, header `Authorization: <key>` — no "Bearer"; key at taostats.io/pro): `/api/subnet/identity/v1` (paginated; `netuid, subnet_name, github_repo, subnet_contact, subnet_url, discord, description, additional` — SDK type omits logo_url), `/api/subnet/latest/v1` (full hyperparams incl. `owner, registration_timestamp, active_validators, active_miners, emission, subtoken_enabled`), `/api/subnet/owner/v1` (owner + coldkey-swap history), `/api/subnet/registration/v1`, `/api/dtao/pool/latest/v1` (`fear_and_greed_index/_sentiment, root_prop, rank, startup_mode, buys/sells/buyers/sellers_24_hr, seven_day_prices`), `/api/dtao/pool/history/v1`, `/api/dtao/subnet_emission/v1`, `/api/delegation/v1` (used by old bot whale module). Official SDK `@taostats/sdk` (github taostat/ts-sdk, exponential backoff on 429). docs.taostats.io and llms.txt are behind a Cloudflare managed challenge (403 for curl/WebFetch). **Tier limits UNVERIFIED**; old bot defaulted `TAOSTATS_RATE_LIMIT_PER_MIN=30` (`config.py:155`).

**C. taomarketcap.com** (Datura AI Corp) — **best free structured source.** Public API `https://api.taomarketcap.com/public/v1/...`, OpenAPI at `https://api.taomarketcap.com/api/public-oas3.json?format=json` (129 paths). **Free tier needs NO key: 10 req/60s burst, 600 req/hour, 100,000 req/month, 2 SSE**; Pro $49/mo (150/60s, 20k/h, 2M/mo, 10 SSE); Business $199/mo (400/60s, 60k/h, 6M/mo, 50 SSE). Auth header `Authorization: <prefix>.<secret>`; responses carry `X-RateLimit-Limit/Remaining/Reset`. Key endpoints: `GET /public/v1/subnets/table/` → all 129 subnets in one call (`name, price, marketcap(_rank), volume, price_difference_hour/day/week/month, logo_url, emission, emission_enabled, is_active, subnet_owner, root_prop, adr, subnet_ema_tao_flow, immune, deregistration_risk (3 true today), owner_personal_locked_alpha, total_locked_alpha, total_subnet_stake, miners_tao_per_day, commits_7d/30d/90d` [110 non-null]); `GET /public/v1/subnets/github-stats/{netuid}/` → `owner, repo, repo_url, last_pushed_at, last_commit_at, commits_7d/30d/90d, is_valid, last_checked_at`; `GET /public/v1/subnets/github-commit-chart/{netuid}/` → daily commit counts (from ~2025-06); `GET /public/v1/subnets/{id}/` → full `latest_snapshot` incl. `subnet_identities_v3{subnetName, githubRepo, subnetContact, subnetUrl, discord, description, logoUrl, additional}`, `subnet_ema_tao_flow`, `largest_locked`, `mechanism_count`; `GET /public/v1/accounts/coldkey-identities/` → 1,088 on-chain coldkey identities (`coldkey,name,url,github_repo,image,discord,description,additional`) for owner-doxxing; `/public/v1/analytics/trending/subnets/` (page views/visitors), `/public/v1/accounts/subnet-holders/{id}/`, staking-activity + SSE streams. Web pages are Next.js with `__NEXT_DATA__` dehydrated React Query (internal `/internal/v1/...` keys); `server-sitemap.xml` has 36,723 URLs (`/subnets/{netuid}/{swaps|holders|miners|validators|weights|tokenomics|conviction|github|registration}`). robots allows all. Links = on-chain only (no twitter).

**D. tao.app** — `https://api.tao.app`, OpenAPI at `/openapi.json` (71 paths), header `X-API-Key`. **Every `/api/beta/*` endpoint, including those labelled "(Free)", returns `401 API key required`** without a key; only `/api/v1/subnets/ohlc` and `/api/v1/portfolio/history` ("(Public)") are IP-rate-limited keyless. Unique data: `/api/beta/analytics/subnets/social/{netuid}/latest` (`server_id, channel_id, messages_analyzed, unique_authors, total_messages, analysis_json, x_tweets[]` — Discord + X analysis), `/social/summary` (per-subnet `latest_unique_authors, latest_total_messages, total_analyses_24h`), `/api/beta/subnets/about` (problem, solution, validators, miners, future plans, benchmark, team members, links), `/api/beta/subnets/owner-content`, `/api/beta/subnets/identity-changes` (`block, sn_name, sn_info` history), `/api/beta/subnet_tags`, `/api/beta/subnet_screener` (`gini_coeff_top_100, hhi, realized/unrealized_pnl_tao, ath_60d/atl_60d, net_volume_tao_1h/24h/7d, emission_pct` + identity fields incl. `subnet_website` [always empty]), `/api/beta/price-sustainability`, `/api/beta/analytics/macro/fear_greed`. Keyless fallback: the home page `https://www.tao.app/` embeds the full screener (130 rows, netuid 0-128) in the RSC `self.__next_f` payload (github_repo 107, subnet_url 102, discord 64). Key signup process UNVERIFIED (no pricing page found; likely via wallet login on tao.app).

**E. backprop.finance** — Next.js RSC; `https://backprop.finance/subnets/{netuid}-{slug}` embeds a curated record: `githubUrls[], twitterUrl, websites[{label: twitter|website|dashboard, url}], categories[{slug,label}]` (28-category taxonomy: data-pipeline, ai-agent, model-development, defi, inference, compute, …), `githubEvents[], subnetContact, subnetUrl, discord, imageUrl, greedFearIndex{index,label}, priceVolumeMetrics{7d,1d,1h: distinctStakers, distinctUnstakers, stakingTransactions, unstakingTransactions, totalBuy/SellVolumeTao}, minerCount, ownerColdkey, pendingColdkeySwapScheduled`. Sitemap: 773 subnet URLs, 129 terminal URLs; robots.txt 404. **ToS explicitly forbids bots/automated control, derivative works, and reverse engineering → treat as manual reference only; no public API.**

**F. bittensor.com / docs** — `bittensor.com/subnets` is 404; the official site has no directory. `bittensor.com/docs/query/subnet-identity` documents the storage item. `docs.learnbittensor.org/subnets` is prose docs, not a list. robots on bittensor.com: `Disallow: /api/`.

**Coverage comparison (website / github / twitter / discord):** subnetalpha ACF 104/106/102/112 (editorial, includes X + telegram, team prose, LinkedIn for 16) · on-chain/TaoStats/taomarketcap/tao.app ≈102/107/0/61-64 (authoritative, no X) · backprop ~ on-chain + curated twitterUrl + multiple labelled websites + categories (ToS-blocked). Recommended merge: netuid-keyed union with source precedence on-chain > subnetalpha ACF > backprop(manual), plus taomarketcap `github-stats` for activity and tao.app `social` (if key obtained) for Discord/X volume.
