## 7. Resolver spec for the new GitHub collector

1. **Normalise** any of: `github.com/{o}/{r}[.git][/tree/..][?tab=..][/]`, `github.com/{o}`, `github.com/orgs/{o}/repositories` → `declared = {kind: repo|owner, owner, repo}`. Denylist placeholders (`username/repo`, `deprecated/deprecated`, `orgs`, `topics`, `sponsors`) → `has_github=0`.
2. **Resolve repo** with redirects disabled: `GET /repos/{o}/{r}` → 200: store `id, full_name, fork, archived, pushed_at, default_branch, stargazers_count, created_at, visibility, open_issues_count, forks_count, ETag`; 301: parse `Location: https://api.github.com/repositories/{id}` → `GET /repositories/{id}` → canonical; emit `repo_renamed` (same owner) or `repo_moved` (owner changed) with {netuid, occupant_key, from, to, id, detected_at}; 404: mark `gone` (deleted/private), emit `repo_gone`, fall back to org enumeration; 403 with `X-RateLimit-Remaining: 0` → sleep to `X-RateLimit-Reset` and retry (never drop the batch); 403 otherwise → `gone`; 429 → `Retry-After`; 5xx → backoff ×3, keep last-good.
3. **Stable key = numeric repo `id`** (persisted; survives rename/transfer — 884216433 constant across rayonlabs→chutesai). Every later cycle verifies by `GET /repositories/{id}` (never by name); `full_name` change → event; 404 on the id → `repo_gone`. Keep `alias_history[]`, `declared_url_by_source{fund,alpha,chain}`, `resolution_method ∈ {direct, redirect, onchain, org_enum, manual}`.
4. **Org enumeration rule**: for each distinct owner: `GET /orgs/{o}/repos?sort=pushed&per_page=100&type=public` (fallback `/users/{o}/repos` on 404). Derive `org_activity = {n_public, n_non_fork, max_pushed_at(non-fork, non-archived), n_pushed_30d, n_archived, n_archived_90d}`. Primary-repo choice when declared is org-only or gone: non-fork ∧ non-archived, ranked by pushed_at, +bonus for name/description matching `/subnet|bittensor|validator|miner|\bsn\s?\d+|netuid/i` or the subnet name token, tie-break stars. Score `github_active` on `max_pushed_at` across org non-fork repos AND report `declared_repo_active` separately; emit `org_repo_archived` when any org repo flips archived (Ditto 08-11 case).
5. **Source precedence**: on-chain identity (owner-signed) > subnetalpha > local snapshot, but compare by resolved id; emit `source_disagreement` when ids differ (20, 117 today) and `identity_repo_changed` when the on-chain string changes (64 changed rayonlabs→chutesai between June and now).
6. **ETag caching**: send `If-None-Match`; on 304 reuse body. **Verified today: unauthenticated 304s DO consume primary quota** (remaining 19→18→17 across three 304s on `/repositories/884216433`), so ETags save bandwidth only; UNVERIFIED for PAT (docs claim 304s are free when authenticated).
7. **Budget**: ~130 occupants × (1 repo + 1 org) + follow-ups ≈ 300 calls/cycle → requires a PAT (5000/h). Unauth 60/h is per-IP and was exhausted by three concurrent agents in <1 h today. Schedule repo re-verify every 6 h, org enumeration daily, 403 → sleep to reset. Zero-quota rename detector: github.com HTML HEAD/GET without redirects + octolytics meta; commit timestamps via `https://github.com/{o}/{r}/commits/{branch}.atom`.
8. **Activity metrics** (authenticated): `/repos/{o}/{r}/stats/participation` (52 weekly counts, may 202-retry) or `/commits?since=&per_page=1` with Link-header page count; taomarketcap github-stats only as a cross-check.
9. **Occupant keying**: (netuid, `network_registered_at`) as the primary key for all fundamentals; on occupant change reset GitHub history and emit `netuid_reoccupied`.
