## Findings

## 0. Bottom line
- taomarketcap's `/public/v1/` is fully keyless (spec `security: [{}, {ApiKeyAuth}]` on all 118 REST paths; SSE paths list only ApiKeyAuth in the spec but anonymous SSE works in practice, tested). Limits printed in the OpenAPI `info.description`, `/llms.txt` and `/developer/pricing/`: **10 req/60 s burst, 600 req/h, 100,000 req/calendar-month (UTC) per IP, 2 concurrent SSE connections**. Pro $49/mo = 150/60 s, 20k/h, 2M/mo, 10 SSE; Business $199/mo = 400/60 s, 60k/h, 6M/mo, 50 SSE. New Free keys are no longer issued (grandfathered). OpenAPI `info.license.name = "Proprietary"`; no ToS page exists anywhere on taomarketcap.com / api.taomarketcap.com / docs.taomarketcap.com (footer links only: API pricing, docs, dashboard). The only usage statement is in `/llms.txt`: "This API is designed for **server-side use and LLM agents**. Browser-based cross-origin requests are not supported (CORS is restricted to a whitelist)." and "For most LLM use cases, the anonymous tier (100,000 requests/month per IP, no key required) is sufficient." => automated server-side use is explicitly the intended use; no attribution/redistribution clause found (UNVERIFIED that none exists behind the developer login).
- **SSE is not metered by the 10/min bucket** (SSE responses carry `X-RateLimit-Limit: 0`). One anonymous `GET /public/v1/sse/subnets/table/` connection (Accept: text/event-stream) delivered a `{"type":"full","data":[129 rows x 44 fields]}` event then `{"type":"delta","changes":{netuid:{changed fields}},"added":[]}` events every block (~12 s). This alone replaces polling the table.
- Rate-limit observation: during this probe the per-IP bucket was repeatedly exhausted by traffic other than mine (`X-RateLimit-Remaining` dropped to 0 within seconds of a window reset while I had made 1-2 requests) => something else on this IP (the parent/sibling probes) was hitting the API. Any client must read `X-RateLimit-Remaining/Reset`, honour `Retry-After` on 429, and use a shared token bucket across all processes on the box.
