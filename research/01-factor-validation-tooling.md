## 5. Exact evidence gates used before capital
1. **In-sample strategy gate** (`__main__.py:1238,1243,1247`; `walk_forward.select_winner` L245): expectancy block-bootstrap 95% CI lower bound > 0 **AND** DSR > 0.95, N = all configs run on the same honest panel (39/61). Result: 0/61 clear it (findings §C).
2. **OOS strategy gate** `_strategy_gate` L438-459: `n_folds ≥ 4` else "advisory only"; `return_basis == "net"` (must run `--realistic-economics`); pooled-OOS expectancy CI.lo > 0; `decay_ratio[E] ≥ 0.25`.
3. **OOS factor gate** `_factor_gate` L568-576: `n_folds ≥ 4`; pooled OOS mean IC > 0 and |t| ≥ 2.
4. **Factor go/no-go decision tree** (`specs/subnet-fundamentals-phase2.md:152-161`, mirrored `specs/strategy-momentum-candidate-validation.md:62-70`): IC positive with **t ≥ 2 on BOTH scopes (live + survivorship)**; **survives `--controls size`** (a vanishing IC ⇒ size in disguise ⇒ NO-GO); monotone-ish decile curve; holds net-of-slippage at `--trade-tao 2`; **DSR > 0.95 necessary-not-sufficient** (on ~200-obs panels nearly every factor clears it); independent **survival test** (`quality_band.py`: bottom-quality tercile death rate ≥ 2× top, non-trivial n, both scopes; death = fwd return ≤ −0.90, `DEATH_RATIO` L32). Always run on a **static snapshot** (`--db data/p0_ledger.db`), never the live writer's DB.
5. **Live-measurability gate** (momentum spec §5 L72-82): `live_signal_coverage` = computable-at-entry-time candidates / in-band candidates, must be materially above the ~23% flow floor over ≥30 days of dry-run before any enforcement — independent of Stage-0 DSR.
6. **Rollout ladder** (`specs/strategy-thin-cap-value.md:244,323-324`; momentum spec §6): flag-off build with inert defaults → dry-run/telemetry ≥ 30 days AND ≥ 40 paper trades, paper net P&L not significantly negative, diversification held, live signal direction matches backtest → live tiny (≤ 10τ) with kill criteria + sentinel kill-switch file.
- Empirical priors (findings §D, 8-month panel, N=8 deflation): `meanrev_z` t −4.9 (size-ctrl −4.4), `size` −4.0 (outlier mirage), `age` +4.0 (+5.6 size-ctrl — cleanest separate axis), `momentum` +4.0, `px_vs_moving` +4.1, `volume_surge` +2.4 (DSR 0.90). **None significant on the ~6-week live panel.** Quality overlay verdict (`data/backtest/results/quality_overlay_2026-06-02.md`): full-universe quality IC negative, collapses under size control (t −2.1 → −0.5) ⇒ size proxy; zero in-band deaths in any tercile ⇒ shelved.

## Gotchas

- spearman_r (app/utils/math.py:45-54) returns 0.0 (not None) for cross-sections with <5 names — a silent zero IC; keep min_names >= 10.
- The old fundamentals dataset is a single 2026-06-02 snapshot; the backtest only partially mitigates look-ahead via quality_static + the reg-block cutoff. TaoSentinel must store as_of per observation so a true point-in-time panel can be built; never forward-fill absent values (factor must return None).
- DSR > 0.95 is a near-universal bar on ~150-225-date panels (every factor clears it) but 0/61 on per-trade strategies; the project treats it as necessary-not-sufficient and leans on size-orthogonality (--controls size), both-scope t>=2, net-of-slippage, and the survival test.
- Deflation variance inconsistency: deflate_factors uses statistics.pvariance of |IC IR| across factors (population), while validate_result/_print_dsr_ranking use sample variance (ddof=1) across configs. deflate_factors also flips negative-mean IC series positive (two-sided test).
- compute_ic uses sample stdev; factor_meanrev_z uses pstdev; zscore uses sample — mixed conventions are harmless for ranks but matter if you port numbers.
- Bar.quality sentinel is -1.0 (absent) — never use 0.0, which is a real low score.
- Slot-reset segmentation triggers on a single-bar price ratio < 0.30; slow multi-bar deaths can partially splice (better caught on the 24h grid). SN115 2026-02-25 (ratio 0.295 with healthy depth) is a false-positive reset that the project keeps deliberately.
- Only 6 deaths in 8 months and 5/6 were at <12 tau depth (below the 3000 tau floor); with the floor on, the bottom decile is healthy-small, not dying — the survival route has almost no events to separate. Expect the same in TaoSentinel unless you include sub-floor names.
- The 'high-hazard tier' actually pays +6% median / +62% mean forward on the death-inclusive panel (thin-cap rebound premium), so 'avoid low-rank' is NOT a free edge; dereg_analysis.py's printed '+12.7% inverts' framing is stale.
- Dense sub-daily history exists only from 2026-04-22 (LIVE_ERA_START); the 4h live panel has ~39% missing buckets and yields only ~2-6 independent OOS folds at H=12/30 — walk_forward refuses to certify under 4 folds.
- IC observations must be non-overlapping: run_factor_study defaults step=horizon; passing --step < horizon autocorrelates ICs and inflates t.
- block_bootstrap_ci picks percentiles by truncated index (int(alpha/2*len)), not interpolation; seed defaults to 0 so results are reproducible but not independent across calls.
- pool_history.tao_in_pool is already TAO (not RAO) — do not divide by 1e9. The SQL downsample relies on SQLite's single-MAX() bare-column rule; other engines need a window function.
- Never read the live ledger.db under the writer (house rule); use the static snapshot (data/p0_ledger.db or a copy).
- subtensor v3.4.6-421 changed emission to e ∝ root_prop × price × (1−miner_burn); net_flow_depth was deregistered and any revived hazard/emission model must include root_prop maturity decay and miner_burn.
- factor_panel.load_factor_panel hard-imports app.config.settings (pydantic-settings) and FundamentalsStore; strip those when porting or the pure functions drag in pydantic.
- walk_forward.py top-level imports pool_history_loader -> engine -> strategy modules; the factor-track functions do not need them but the module import will fail without the whole app tree.
- Block->unix calibration for factor_age is anchored on Finney block 6_502_594 <-> ts 1_758_585_588 at 12.0 s/block; re-anchor on a fresh observed pair if reused.
