## 1. TaoStats API (https://api.taostats.io)

**Access.** Docs at docs.taostats.io are Cloudflare-gated (HTTP 403 "Hello there, human!" for non-browser fetches, including /llms.txt), so the endpoint inventory below was reconstructed from the official `@taostats/sdk` v1.2.0 source (github.com/taostat/ts-sdk, `src/modules/*/`) plus the old bot's client. Auth header is the raw key, no Bearer: `Authorization: <API_KEY>` (ts-sdk `src/client/http-client.ts:37`; old bot `E:\SN_Trader\SubnetTrader\app\data\taostats_client.py:55-59`). Keys from https://taostats.io/pro/api-keys. Response envelope: `{data:[...], pagination:{current_page, per_page, total_items, total_pages, next_page, prev_page}}`; params `page`, `limit` (SDK default 20, MAX_PAGE_SIZE 100; old bot passed `limit=200` on pool/latest and received all subnets — per-endpoint cap UNVERIFIED). Money fields are strings in rao (1e9 rao = 1 TAO); `price` is TAO per alpha as string.

**Pricing / limits.** Free: 5 calls/min, 10k calls/month. Standard: $49/mo, 60 calls/min, 50k calls/month. Pro/Enterprise: "application-specific rate limits, dedicated SLA" (numbers UNVERIFIED). Old bot measured free tier: HTTP 429 after 5 calls in ~7s, body `{"status_code":429,"message":"Rate Limited. Try Again Later."}`, no rate headers (`specs\feature-whale-wallet-tracker.md:82-84`); the $50/mo plan's monthly quota was exhausted by polling (`specs\migrate-taostats-to-sdk.md:4,15`). Usage endpoint: `GET /api/api-usage` (docs page "Get API usage", exact path UNVERIFIED). Hosted RPC (keyed): `wss://api.taostats.io/api/v1/rpc/ws/finney_archive?authorization={API_KEY}` (ts-sdk `constants.ts`); a lite variant exists per docs "Hosted RPC Connectivity" (path UNVERIFIED).

## 2. Bittensor Python SDK

**Current version:** `bittensor` **11.1.0** stable (PyPI, 2026-08-14); pre-releases 11.3.0rc59 (2026-09-22). "Bittensor 11" is one package (SDK + `btcli` + wallet) built from the subtensor monorepo `RaoFoundation/subtensor` `sdk/python` (org renamed from opentensor). v10.x (old `opentensor/bittensor`) stays installable but frozen; the old bot ran 10.1.0. Python 3.10–3.14; Linux x86_64/aarch64 + macOS; **Windows only via WSL** (confirms the user's move to Ubuntu). Install: `uv pip install bittensor` after uninstalling `bittensor-cli` and `bittensor_wallet`. Env: `BT_NETWORK` (was `BT_SUBTENSOR_NETWORK`).

**Client:** `sub = bt.Subtensor()` (blocking; `"finney"` default, `"test"`, `"local"`, or `ws://...`), `client = await bt.Subtensor()` / `async with bt.Subtensor() as client` for async (single class replaces Subtensor/AsyncSubtensor). Reads are typed namespaces; any read also via `sub.read("<name>", ...)`; raw storage via `sub.query(bt.storage.SubtensorModule.Tempo, [netuid])`. Many reads accept `block=` for block-pinned snapshots (needs archive node beyond ~300 blocks). CLI mirrors: `btcli query <name> --json`. Machine-readable catalog: https://bittensor.com/catalog/reads.json.

**Subnet reads (v11 names → old v10):**
- `sub.subnets.subnets()` (→ `all_subnets()`; four batched map queries over NetworksAdded/Tempo/Burn/SubnetworkN); `sub.subnets.subnet(netuid)` / `client.subnets.info(netuid)` (→ `subnet(netuid)`/`get_subnet_info`); `sub.subnets.subnet_identity(netuid)` (storage `SubnetIdentitiesV3`: `subnet_name, github_repo, subnet_contact, subnet_url, discord, description, logo_url, additional`); `sub.subnets.subnet_names()`; `sub.subnets.subnet_hyperparameters(netuid)` (flat dict; → `get_subnet_hyperparameters`); `sub.subnets.subnet_registration_cost()`; `sub.subnets.subnet_start_schedule(netuid)`; `sub.subnets.subnet_tao_flows()` (per-subnet EMA net TAO flow, rao/block); `sub.subnets.commit_reveal_enabled`, `mechanism_count`, `mechanism_emission_split`.
- Prices: `sub.prices.alpha_price(netuid)`, `sub.prices.alpha_prices()` (all subnets, TAO/alpha), `quote_stake(netuid, amount_tao)`, `quote_unstake(netuid, amount_alpha)` (alpha/TAO out, fee, slippage). - Metagraph: `sub.subnets.metagraph(netuid, block=...)` (→ `metagraph(netuid)`; no `.sync()`, refetch instead). Per-neuron records (`uid, hotkey, coldkey, incentive, emission, total_stake, ... validator_permit, trust/validator_trust/consensus/dividends`; spec ≥435 adds `collateral_locked, collateral_min, collateral_earned`); `name`/`symbol` wire-encoded as compact u16 utf-8 vectors. - Hyperparams: `sub.hyperparameters.immunity_period / difficulty / max_weight_limit / min_allowed_weights / subnet_emission_enabled / reveal_period(netuid)`. Epochs: `sub.epochs.epoch_status(netuid)`, `blocks_until_next_epoch`, `blocks_since_last_step`. Chain: `sub.block()`, `sub.chain.block_info(block)`, `sub.chain.block_time()` (12.0s). ## 3. dTAO mechanics for scoring

- **Block emission:** 12 s blocks; was 1 TAO/block, first halving hit in **Dec 2025** (issuance crossed 10.5M) → **0.5 TAO/block (~3,600 TAO/day)**; halvings are issuance-threshold based (next 15.75M, 18.375M); burns/recycling push halvings out.
- **Per-subnet TAO share (price-based, since spec 423 / v3.4.8-423, released 2026-06-25; PR #2781 "Price-based emissions with miner-burn scaling" merged 2026-06-22; mainnet deploy ~2026-06-24):** `demand_i = price_ema_i / Σ price_ema` (storage `SubnetMovingPrice`, spot capped at 1.0; EMA smoothing `ema_alpha = base_alpha × blocks_since_launch/(blocks_since_launch+201,600)` so new subnets start near zero); `× (1 − MinerBurned_i)` (fraction of last tempo's miner incentive withheld to owner hotkeys); then **Emission Gate (v440, July 2026):** `gate_i = 1/(1+(θ/share_i)^h)`, `h=3`, θ = 32nd-highest adjusted share (recomputed every 360 blocks; quantile q≈0.61) — at the bar a subnet keeps 50%, mid-tail 15–30%, deep tail 1–5%; mainnet snapshot: below-bar emission 38.4%→12.5%, top-8 32.8%→52.7%, 80% of emission reached by rank 23 (was 64). Note: the task's "v3.4.6" tag was not found (tags seen: v3.4.5-419 security hotfix, v3.4.7-422, v3.4.8-423, v3.4.9-424 2026-06-29); after 424 releases are runtime-numbered (v431…v469 proposed 2026-09-22). Alpha injection also capped by `root_prop_i × alpha_emission_i`.
- **Alpha:** each subnet mints up to 1 alpha/block `alpha_out` (to participants at epoch end) + `alpha_in` = `tao_in/price` capped at `root_proportion × alpha_emission`, `root_proportion = root_tao×tao_weight/(root_tao×tao_weight+alpha_issuance)`, `tao_weight = 0.18`; as alpha issuance grows the cap falls and excess TAO buys alpha on the pool (protocol-owned alpha). Alpha halvings begin ~2028/29. Pools are Balancer-style weighted (`price = (w_alpha/w_tao)×(TAO_reserve/alpha_reserve)`, weights 0.5/0.5 initially, bounded [0.01,0.99]); injections shift weights not price. User liquidity (swap v3 ticks) exists per pool (`enabled_user_liquidity`, `swap_v3_initialized`, `current_tick`, `fee_rate`).
- **Tempo split:** 18% owner (`SubnetOwnerCut=11796/65535`; toggle `owner_cut_enabled`; miner emission to owner hotkey is burned), 41% miners, 41% validators+stakers; a `root_proportion` slice of the validator half goes to root TAO stakers only if Σ EMA prices of eligible subnets > 1.0, else recycled. Validator dividends split TAO vs alpha stakers by `τ×w/(α+τ×w)`. Tempo default 360 blocks (~72 min, owner-adjustable 360–50,400); ≤2 subnet epochs per block.
- **Registration:** cost **doubles on each subnet registration** then decays linearly over `NetworkLockReductionInterval` 100,800 blocks (~2 weeks); floor stated as 1,000 TAO in current docs (UNVERIFIED — constant not found in code search; earlier floor was 100 TAO); network rate limit 1 subnet registration per 7,200 blocks (~1 day); lock is non-refundable and becomes the pool's initial TAO reserve; a 2026 hotfix ended the owner's free alpha at registration (UNVERIFIED date). New subnets register with `subnet_emission_enabled=0` (root flag) and need owner `start-call` after the activation delay.
- **Immunity & deregistration:** `NetworkImmunityPeriod = 1,296,000 blocks` (runtime/src/lib.rs:962) = 180 days ≈ 6 months (older learnbittensor text saying 4 months is stale). When `SubnetLimit` is full, the next `register_network` prunes the **non-immune subnet with the lowest EMA alpha price** (ties → oldest); price-ranked pruning replaced emission-ranked in Sept 2025; all UIDs deregister, TAO reserve is distributed pro-rata to alpha holders as free balance (not restaked), netuid reused. Learnbittensor also states dereg at most once per 2 days (UNVERIFIED). Neuron `immunity_period` default 4,096 blocks; `max_allowed_uids` default 256 (min 64), `max_allowed_validators` default 128; `max_allowed_uids × mechanisms ≤ 256` (up to 2 mechanisms).
- **Subnet limit / count:** current bittensor.com docs say **128**; subnetalpha.ai lists 128; BSCN/avark claim the "Robin τ" doubling to **256 shipped May 2026** — CONFLICT, UNVERIFIED. Resolve at runtime with `sub.query(bt.storage.SubtensorModule.SubnetLimit)` and `TotalNetworks`/`subnets()`.
- **Other 2026 runtime changes:** v431 (Jul) conviction locks + subnet ownership transfers to most-convicted hotkey after 1 year (v446/447: gate = single hotkey vs 18% eligible-alpha threshold), Rust SDK; v437 miner registration collateral (`collateral_policy`: lock_share, drain_ratio); v441 **Root Reborn** — root dividends accumulate in per-validator baskets (beta tokens), `claim-root-with-hotkey`, no mechanical sells; root validators no longer vote on subnet emission; v445 fee recycling, multisig btcli; v446 Liquid Alpha consensus modes; v448 linked orders, bulk exits; v450 basket curation with concentration caps (≤1/16 NAV); v461 (Sep) `swap-basket`/BasketTrading proxy (2% price bands, 10% daily turnover), **`set_root_weights` removed**; v467 halves tx fees; also configurable tempo/owner-triggered epochs, advanced limit orders pallet, governance V2, EVM precompiles (metagraph, subnet, staking v2, alpha, leasing, crowdloan, `getNetworkRegistrationBlock`), leases/crowdloans (lease shares a % of the 18% owner cut). Default 5% slippage protection on stake txs; TAO ≈ $318 (taostats snapshot).
