## Findings

## 0. Bottom line
- **Trigger.** A subnet is deregistered only inside a successful `register_network` extrinsic when the network is at `SubnetLimit`; there is no periodic pruning, no inactivity rule, and no emission-rank rule. Exactly one subnet is dissolved per registration. If every non-root subnet is immune the registration fails with `SubnetLimitReached` instead. **[CODE]** `pallets/subtensor/src/subnets/subnet.rs:192-214,234`; the only caller of `do_dissolve_network` is that path (`subnet.rs:234`; grep over `subnet.rs`, `dissolution.rs`, `lib.rs`, `admin-utils/src/lib.rs`).
- **Selection.** `get_network_to_prune()` iterates `NetworksAdded`, skips root and every subnet with `current_block < NetworkRegisteredAt + NetworkImmunityPeriod`, and picks the **lowest `SubnetMovingPrice`** (via `get_moving_alpha_price`; root/stable mechanisms count as 1.0); **ties go to the earliest `NetworkRegisteredAt`**. **[CODE]** `pallets/subtensor/src/coinbase/root.rs` (fn body after `:333`), `staking/stake_utils.rs:33-44`. A subnet that never called `start_call` has no `SubnetMovingPrice` entry → default **0** → it is culled first once its immunity ends (`lib.rs:1394` `DefaultMovingPrice = 0.0`).
- **Immunity = 864,000 blocks = 120.0 d, unchanged since our 2026-09-22 read.** Live storage `NetworkImmunityPeriod = 864000` **[CHAIN]**; TaoStats `age + immunity_blocks_remaining = 864,000` for all 7 immune entries at block 9,246,248 **[TAOSTATS]**; TMC boundary: oldest immune 836,412 blocks, youngest started non-immune 894,266 **[TMC]**. ## 1. Mechanics in detail **[CODE]**
1. `do_register_network` (`subnet.rs:148-281`): signed coldkey → `current_block ≥ NetworkRegistrationStartBlock` → global rate limit (`TransactionType::RegisterNetwork`, limit `NetworkRateLimit`, last block = `get_network_last_lock_block()` = `LastRateLimitedBlock[NetworkLastRegistered]`) → identity check → **count = |NetworksAdded ∖ root| + |DissolveCleanupQueue|; if ≥ SubnetLimit**: if the cleanup queue is longer than the registration queue, wait; else `prune_netuid = get_network_to_prune()` or fail `SubnetLimitReached` → lock = `get_network_lock_cost()`, must be affordable → `do_dissolve_network(prune_netuid)` → registration is **queued** (lock escrowed, `NetworkRegistrationQueued` event), `set_network_last_lock(lock_amount)`, `set_network_last_lock_block(current_block)`.
2. `do_dissolve_network` (`subnets/dissolution.rs:124-166`): `NetworksAdded::remove(netuid)`, `TotalNetworks −= 1`, pushes the netuid to `DissolveCleanupQueue`, emits `NetworkRemoved(netuid)`. The metered cleanup runs in `on_idle` (`macros/hooks.rs:261`), phases `SubnetRootDividends… → AlphaInOutStakesGetTotalAlphaValue → AlphaInOutStakesSettleStakes` (holders' alpha "pro-rata converted to coldkey free TAO", `dissolution.rs:17,202`) → locks/collateral cleared; then `process_network_registration_queue` (`hooks.rs:266`) finalises the new subnet and sets `NetworkRegisteredAt = current_block` (`subnet.rs:381`). ⇒ the dereg *event* is the registration tx block; netuid reuse lags by the cleanup.
3. Payout rules **[DOC]**: TAO reserve distributed pro-rata over alpha to coldkey free balance, not restaked; conviction locks deleted uncompensated (bittensor.com/docs/guides/subnets); protocol-owned alpha (`SubnetProtocolAlpha`, `SubnetAlphaIn` on post-cutover subnets) share withheld/recycled, owner refund (legacy subnets only) `max(0, lock_cost − owner_received_emission_in_tao)` (taostats.io/docs/concepts/subnets/subnet-deregistration, reviewed 2026-09-15; TMC changelog v413/v415).
4. `start_call` (`subnet.rs:547-565`): allowed once `block ≥ NetworkRegisteredAt + StartCallDelay` (`InitialStartCallDelay = 0`, `runtime/src/lib.rs:979`; live storage not read — UNVERIFIED), sets `FirstEmissionBlockNumber`. Until then: no emission, no moving-price updates, `SubnetMovingPrice` absent (= 0). Immunity is counted from **registration**, not from start_call. Today SN86 (registered 76.8 d ago), SN59 (42.7 d) and SN82 (12.6 d) are not started; SN86's immunity ends in 311,036 blocks ≈ 43.2 d (block 9,557,284): if it has not started by then it is the next cull with `mp = 0` regardless of every other subnet's price.
5. History: BIT-0004 (authored 2025-08-12) proposed lowest-*emission* pruning; PR #1685 (merged 2025-09-17) shipped the dTAO-compatible version; the 2025-09-25 deploy (PR #2066) set SubnetLimit 128, 4-month immunity, rate limit "2 → 4 days", lock interval 8 d, initial lock 2,000 τ, registrations resumed 50,400 blocks later; chainbuying dates the first post-pause registration to 2025-10-19. Rate limit is now 14,400 blocks (2 d) and the stored interval 115,200 — when those were changed is UNVERIFIED (admin-utils `sudo_set_network_rate_limit` / `sudo_set_lock_reduction_interval` are `Normal` calls since v377).

## 3. "Distance from deregistration" metric set (proposal for the spec)
Inputs per occupant i at head block B: `reg_i` (`NetworkRegisteredAt`), `mp_i` (`SubnetMovingPrice`, **0 when absent**), `p_i` (spot), `fe_i` (`FirstEmissionBlockNumber`, None = not started), `emission_enabled_i`; constants `IMM = 864,000`, `RL = 14,400`, `a = 0.0003`, `Hb = 201,600`, `L`, `last_reg_block`, `I_eff = 57,600`. All blocks → days at 7,200/day.
1. `immunity_end_block_i = reg_i + IMM`; `immunity_remaining_days_i = max(0, immunity_end_block_i − B)/7200`; `immune_i = remaining > 0`. (Keep 05 §2.4; add `immunity_end_block` as a stored field so graduation schedules are a simple query.)
2. **Pool** `P(t) = {j ≠ 0 : added_j ∧ ¬immune_j(t)}` — includes not-started (mp 0) and emission-disabled occupants (both are chain-eligible). `dereg_rank_from_bottom_i = 1 + |{j ∈ P : (mp_j, reg_j) <_lex (mp_i, reg_i)}|` (lower mp first; equal mp → earlier registration first). Report also `pool_size`.
3. **Expected culls in horizon H** `k_H = clip(round(H / g), 0, floor(H / 2))` where `g` = trailing-90-d mean inter-registration gap (8.0 d today → `k_30 ≈ 4`, `k_90 ≈ 11`). Make `g` a measured network metric (`reg_gap_mean_90d`), not a constant; fall back to `DEREG_CULLS_PER_30D = 4`.
4. **Graduation-adjusted pool** `P_H = P ∪ {j immune : immunity_end_block_j ≤ B + 7200·H}` with each graduate's current `mp_j` (0 if not started); `rank_H_i` and `pool_H` over it. Worked example today: SN92 rank 1 in P → rank 3 in P_30 (SN16, SN99 graduate below it), rank 6 in P_90 (plus SN86 @0, SN103, SN70).
5. **Cull line & gap**: `cull_line_k = k-th lowest mp over P_H ∖ {i}`; `mp_gap_to_cull_line_k_i = mp_i / cull_line_k − 1` for k = 1 and k = k_H (≤ 0 ⇒ inside the expected cull set; TMC's `deregistration_risk` corresponds to k = 3 on spot). Today SN92: gap_1 = −21.6 % (vs SN47), SN47: gap_1 = +27.6 %, SN72: +18.5 %.
6. **Spot leading indicators**: `spot_rank_from_bottom_i` over P_H using `p_i`; `mp_vs_spot_i = p_i/mp_i − 1` (negative ⇒ mp will keep falling); `half_life_h_i = ln2 / α_eff_i / 300` with `α_eff_i = a·b_i/(b_i + Hb)`, `b_i = B − (fe_i − 1)`.
7. **Days to cross a line under constant spot** (valid when `p_i < C < mp_i`): `n* = ln((mp_i − p_i)/(C − p_i)) / (−ln(1 − α_eff_i))` blocks. Because half-lives are < 10 h, for horizons ≥ 1 d model `mp_i(t) ≈ p_i(t − 1/α_eff_i)` (lag 11–14 h) and let spot carry the projection: `p_i(t) = p_i·exp(μ_i t)` with μ_i from 7-d/30-d log-returns (1 h `price_bars`), σ_i from 30-d realised vol.
8. **`estimated_days_to_cull_i`** (report as a distribution, not a point): Monte-Carlo over H days — spot GBM(μ_i, σ_i) for i and for the pool/graduates (or static competitors as a baseline), registrations as a renewal process with mean `g` and minimum spacing 2 d, first registration ETA from the lock-cost curve (`cost(Δ) = 2L − L·Δ/I_eff`; registrants have bought near `cost ≈ L`, i.e. ≈ 8 d after the last registration → next ≈ 2026-10-12 ± 3 d), graduates join P at their `immunity_end_block`, each registration culls `argmin_lex(mp, reg)` over the current pool. Outputs: `p_cull_30d`, `p_cull_90d`, `median_days_to_cull` (∞ if never culled in the simulated horizon). Deterministic fallback for the UI: `days_to_cull_static = days until the (rank_H_i)-th registration` = `eta_next_reg + (rank_H_i − 1)·g` when `rank_H_i ≤ k_H`, else "> H".
9. **`dereg_recovery_ratio_i = liq_price_i / p_i`** — what a holder receives per alpha if culled, vs spot; `liq_price` per TaoStats' definition (TAO pot ÷ alpha incl. protocol-owned alpha for post-cutover subnets; formula UNVERIFIED — calibrate against the liq price TaoStats shows). An investor cares about distance *and* recovery.
10. **Network-level**: `blocks_since_last_registration`, `earliest_next_registration_block = last_reg_block + RL`, `lock_cost_now`, `lock_cost_days_to(L)`, `reg_gap_mean_90d`, `k_30d`, `pool_size`, `graduates_30d/90d`. These make the "deregistration weather" visible on the dashboard and feed every per-subnet metric above.
11. **Scores**: `dereg_safety_H = 1.0 if immunity_remaining_days > H else clip((rank_H_i − k_H)/(pool_H − k_H), 0, 1)`; `dereg_imminent_H = (rank_H_i ≤ k_H)`. Keep `dereg_hazard` (ported module) as the smooth auxiliary, fed with the P_H moving-price map and the spot rank.
