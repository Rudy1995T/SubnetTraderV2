## 5. Cost model (gap = block 8,443,757 → 9,123,669 = 679,912 blocks = 2,272.8 h = 94.7 d; pre-ledger dTAO era = 4,920,351 → 6,502,594 = 5,274 h)
One bucket = `chain_getBlockHash` + `state_getStorage(Timestamp.Now)` + `state_call SubnetInfoRuntimeApi_get_all_dynamic_info` (= what `AsyncSubtensor.all_subnets(block=)` in `backfill_metadata.py:90` / `backfill_rpc_candles.py:180` does; ~47-49 KB SCALE, ~94 KB hex JSON; decode with `async-substrate-interface` `runtime_call`, which installs on Windows per `dev-pc-chain-probe-setup.md`, or the bittensor SDK on Linux).
- Gap hourly: 2,273 buckets / 6,819 calls / ~214 MB. OnFinality unpaced (≤5 RPS): **~25-30 min**. Opentensor archive at 0.5-2 s pacing: **~57-76 min**.
- Gap 15-min: 9,091 buckets → OnFinality ~1.7 h, archive ~3.8 h. 5-min: 27,274 → ~5 h / ~11 h. 1-min (old ledger cadence): 136,370 → 25 h / 57 h — not worth it; take 5-min price from TMC instead.
- Pre-ledger hourly (2025-02-13 → 2025-09-22): 5,274 buckets → OnFinality ~1 h, archive ~2.2 h.
- TMC: 129 subnets × 1 call = 129 calls ≈ **13 min at 10/min** per series (5m candles whole gap; analytics 1M hourly; analytics 1Y daily).

## 6. Recommended backfill sequence
1. **Recover the Pi ledger first** (Section 7); it may already hold 1-min data to ≥2026-07-08. Merge by `(netuid, block_number)`; the gap then starts at the Pi's `MAX(timestamp)`.
2. TMC `candle-chart-compact?period=5m` whole-gap per subnet (129 calls) → price/volume/`start_volume` at 5-min; stamp rows by `timestamp`, map to block via step 4's `Timestamp.Now` index (not TMC candle `block_number`).
3. TMC `analytics/subnet/{n}/?span=1M` (hourly `subnet_tao` etc. for the last 30 d) and `?span=1Y` (daily `subnet_tao`, supply, emission share, locked alpha for the whole gap and back to 2025-09-22) — 258 calls.
4. RPC hourly cross-section for the whole gap via OnFinality public (fallback opentensor archive with ≥1.5 s/bucket and retry on -32004 with exponential backoff): fills `tao_in_pool, alpha_in_pool, moving_price, subnet_volume, emission` for all 129 subnets at true block timestamps → write to the old `pool_history` schema (or the `pool_history_hourly` rollup table from `specs/ops-pool-history-retention.md`), keeping `backfill_metadata.py:53-66`'s `moving_price IS NULL` write gate and per-bucket commit.
5. Optional: pre-ledger hourly 2025-02-13 → 2025-09-22 (OnFinality ~1 h) so death-inclusive factor panels cover the full dTAO era.
6. Forward capture on the Ubuntu box: poll `entrypoint-finney`/`lite` every 1-5 min (state retained ~7-13 h); on restart, if the last row is older than ~6 h, catch up from OnFinality/archive by hour, never from lite. Register a free OnFinality key (40 rps) to remove the 5 RPS/-32029 risk.
